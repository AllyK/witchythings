# Witchy Things

A small portal of rituals, moon work, and dreamwork, built as plain HTML with no build step, no dependencies, and no tracking.

## What is here

- `index.html` is the main portal page.
- `moon-majic/` holds the Moon Majic portal: an eclipse ritual (solo and paired versions), new moon rituals by sign, and full moon rituals by sign.
- `dreamwork/` holds the dreamwork method page and `dream-log.html`, a downloadable offline dream tracker. The tracker saves entries to the browser's local storage on the reader's own device; nothing is sent anywhere. It includes dashboards for feelings over time, distress trends, and recurring images, plus a weekly review view, and JSON export and import for backups.

## Publishing on GitHub Pages

1. Create a new repository (for example `witchy-things`) and push this folder's contents to it.
2. In the repository, go to Settings, then Pages.
3. Under Source, choose "Deploy from a branch," pick your default branch and the root folder, and save.
4. The site appears at `https://<your-username>.github.io/witchy-things/` within a few minutes.

Every page is self-contained, so you can also share any single HTML file on its own, including the dream log.

## A note on the content

Each page says plainly what is inherited from named traditions and sources and what is invented as a personal framework. Only the practitioner decides what any of it means.
